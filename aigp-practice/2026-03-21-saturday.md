**Q1.** [Domain IV.B | Bloom: Analyze] ⚠️ CLOSE-PAIR

An organization's legal team is reviewing a licensing agreement with a proprietary AI model provider. The agreement includes a clause stating: *"Provider shall not be held liable for any outputs generated through the API; all regulatory obligations arising from model outputs are borne exclusively by the Licensee."* Which governance risk does this clause MOST directly create for the deploying organization?

A) Intellectual property risk, because the non-exclusive license prevents the organization from claiming ownership over AI-generated outputs used in its products

B) Data privacy risk, because the clause implicitly grants the provider permission to use the organization's API inputs for model retraining without additional consent

C) Vendor concentration risk, because the clause creates financial dependency on a single provider whose business continuity directly affects the organization's operations

D) Liability concentration risk, because the deploying organization bears sole legal and regulatory responsibility for all AI-generated outputs and their consequences — regardless of how limited its visibility into the model is

**Q2.** [Domain IV.C | Bloom: Apply] ⚠️ CLOSE-PAIR

According to AI governance principles, which statement CORRECTLY classifies these controls?

A) Both Control X and Control Y are preventive controls because they both aim to protect the integrity of the production AI system from harmful changes

B) Control Y is a preventive control because it stops problems before they occur in production; Control X is a detective control because it identifies deviations after the system is already live

C) Control X is a preventive control because it proactively monitors the system on a continuous basis; Control Y is a detective control because it validates whether changes meet requirements

D) Both Control X and Control Y are detective controls because both are triggered by observed system behavior rather than acting in advance of any AI processing

**Q3.** [Domain IV.C | Bloom: Evaluate] — Case Study

An insurance company's AI underwriting model has been in production for two years. A quarterly audit reveals that the model's accuracy for a rapidly growing customer segment — remote workers with non-traditional employment patterns — has fallen to 58%, well below the 80% performance threshold defined in the model's governance documentation. This segment now represents 22% of all applications. Which response BEST demonstrates a mature deployment governance posture?

A) Activate the model refresh protocol: suspend automated underwriting for the affected segment, implement human review as a compensating control, initiate root cause analysis and retraining on current data, conduct validation testing inclusive of the new segment, and obtain stakeholder sign-off before redeployment

B) Immediately deactivate the AI system for all customer segments and revert to fully manual underwriting for all applications until a completely new model is trained from scratch

C) Lower the documented performance threshold from 80% to 65% to align governance requirements with the model's demonstrated current capabilities

D) Continue using the model unchanged while adding a disclaimer to affected customers acknowledging that automated underwriting accuracy may vary for non-traditional employment profiles
